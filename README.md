# Task 3 - Pandas Data Analysis

## About
This project performs data analysis and visualization using Python and Pandas.

## Objectives
- Create and analyze student data using Pandas
- Calculate average marks and attendance
- Find highest and lowest marks
- Analyze department-wise performance
- Create graphs for data visualization

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files
- `task3_pandas.py` - Python source code
- `student_data.csv` - Student dataset
- `student_marks.png` - Student marks visualization
- `average_marks_department.png` - Department-wise average marks
- `attendance_vs_marks.png` - Attendance vs marks visualization

## Key Results
- Average marks: 77.60
- Average attendance: 85.00%
- Highest marks: 91
- Lowest marks: 61
- Department with highest average marks: ME

## Conclusion
The project demonstrates basic data analysis, data cleaning, and visualization using Pandas and Matplotlib.
